Pokémon Champions Support — WEB v17

このフォルダは「ローカルHTMLを直接開く版」ではなく、静的Webサイトとして公開するための構成です。

公開方法（例）
- Netlify: このフォルダまたはZIPをDeployへアップロード
- GitHub Pages: リポジトリ直下に中身を置き、Pagesを有効化
- Cloudflare Pages: 静的サイトとしてこのフォルダを公開

公開後は https://... のURLをGoogle Chromeで開いて使います。
入口は index.html です。

主な継承機能
- SMART UI
- 環境データ
- クイック選出
- パーティ構築総合判定
- 苦手ポケモン対策候補
- メガ枠0/2・1/2時のメガ候補推薦
- メガX/Yのストーン別評価
- 使用率％は小数1桁表示
